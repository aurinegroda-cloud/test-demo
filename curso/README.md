# Creador desde cero

Curso paso a paso para empezar desde cero en YouTube, TikTok, Instagram, Hotmart y Shopify.

- Versión navegable: https://claude.ai/artifact/WbT4p34uo6cF8D8CstBiDT (también `curso.html`, se abre en cualquier navegador).
- Capítulos en Markdown: `00-ruta.md` a `07-herramientas.md`.
- Para regenerar `curso.html` después de editar un capítulo: `pip install markdown` y `python3 curso/build.py`.

Datos verificados al 28 de noviembre de 2026. Requisitos, comisiones y disponibilidad por país cambian seguido: revisa las fuentes de cada capítulo.
